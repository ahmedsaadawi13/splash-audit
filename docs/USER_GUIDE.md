## Getting Started

### First Login

1. Navigate to your SplashAudit URL
2. Enter your email and password
3. Change your password on first login (recommended)

### Dashboard Overview

The dashboard provides:
- Quick statistics (findings, audits, risks)
- Recent activity
- Upcoming deadlines
- Quick links to common tasks

## Managing Audits

### Creating an Audit Plan

1. Navigate to **Audit** > **Plans**
2. Click **Create New Audit Plan**
3. Fill in required fields:
   - Title
   - Type (financial, operational, compliance, IT, etc.)
   - Planned start/end dates
   - Description
4. Click **Save**

### Managing Audit Checklists

1. Navigate to **Audit** > **Checklists**
2. Create checklist with items
3. Assign to audit plan
4. Execute checklist items during audit

## Findings & Corrective Actions

### Creating a Finding

1. Go to **Findings** > **Create**
2. Fill in:
   - Title
   - Description
   - Severity (High, Medium, Low)
   - Audit Plan
   - Assigned user
3. Optional: Add cause, effect, criteria
4. Click **Save**

### Creating Corrective Actions

1. Open a finding
2. Click **Add Corrective Action**
3. Enter action description and due date
4. Assign responsible person
5. Track progress until completion

---

## Risk Management

### Adding Risks

1. Navigate to **Risk** > **Register**
2. Click **Add Risk**
3. Enter:
   - Risk title and description
   - Category
   - Likelihood (1-5)
   - Impact (1-5)
   - Control measures
4. System calculates inherent and residual risk

### Risk Heatmap

View all risks on interactive heatmap:
- Navigate to **Risk** > **Heatmap**
- Color-coded by severity
- Click cells for details

---

## Compliance Tracking

### Managing Compliance Requirements

1. Go to **Compliance** > **Areas**
2. Create compliance area (ISO 27001, SOX, HIPAA, etc.)
3. Add requirements to area
4. Perform compliance checks
5. Track non-conformances

## Reports

### Available Reports

1. **Audit Summary** - Overview of audit results
2. **Findings by Severity** - Breakdown of findings
3. **Corrective Actions Status** - Action tracker
4. **Risk Register** - Complete risk inventory

### Exporting Reports

- Click **Export CSV** on any report
- Data downloads immediately
- Open in Excel or Google Sheets

---

## User Management

### Adding Users (Admin Only)

1. Navigate to **Users**
2. Click **Add User**
3. Enter user details
4. Select role:
   - Platform Admin
   - Tenant Admin
   - Audit Manager
   - Internal Auditor
   - Process Owner
   - Reviewer
   - Viewer
5. Send credentials to user
